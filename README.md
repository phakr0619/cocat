# Cocat

化学構造式と反応スキームを描くための、ブラウザで動くエディタ。名前は co-catalyst（助触媒）から。

- 構造式を描き、ChemDraw の形式（CDXML・CDX）、MOL、SMILES、SVG、PNG で読み書きできる
- 反応スキームを「データ」として持つ。化合物・反応・条件を入れると、書式（ACS 風など）どおりに自動で配置し、書式を切り替えて描き直せる。化学量論表と検討表（論文の Table の体裁）も作れる
- AI の手伝い（任意）: 言葉から作る、言葉で直す、画像や論文の PDF の図からスキームを起こす。AI の答えは下書きにし、構造（RDKit）・元素のつじつま・立体を確かめてから人が確定する

公開しているサイト: https://d14qbvc5cn8yze.cloudfront.net/

## データの扱い

- 描いた構造とプロジェクトは、ブラウザの中（IndexedDB）だけに置く。公開している側には届かない
- AI の機能は、利用者が自分で作った API キー（今は Google の Gemini）で、ブラウザから AI の会社へ直接呼ぶ。キーはブラウザの中だけに置き、公開している側には送らない。何を送るかは送る前に見られる
- 使い方の統計は個人を特定しない形で取る（機能の名前だけ。「このツールについて」で止められる。`docs/hosting.md` の「アクセス解析」）

## できること

| 分類 | 操作 |
| --- | --- |
| 結合 | 単・二重・三重・くさび（実線・破線）・波線。何もない所のクリックで右上 30° に1本、原子のクリックで空いている向きに1本（鎖は 120° のジグザグ）、ドラッグで 30° 刻みの任意の向き（終点が原子の近くならつなぐ）。既存の結合のクリックで 単→二→三、二重結合ツールでは線の位置（自動→中央→右→左）、同じくさびで向きの反転 |
| 鎖 | 鎖ツールでドラッグした長さぶんのジグザグ鎖 |
| 原子 | 置換基の記号 R・R1・R'・Ar・X をラベルに入れられる（R1 は R¹ で描き、SMILES では *）。原子にカーソルを合わせて C N O S F P / L(Cl) B(Br) I H、M(Me) E(Et)、+ / - で電荷。Enter かダブルクリックでラベル入力（NH2, OH, N+, OMe, Boc など。NH2Cl・NH·HCl で塩酸塩）。水素は自動で付けて、結合のない側に出す（H2N, HO） |
| 略号 | 標準の 49 種（Me Et Pr iPr Bu tBu Ph Bn Bz Ac Piv Boc Cbz Fmoc PMB TMS TBS TIPS Ts Ms Tf OMe OAc CO2Me CO2Et CO2H CN NO2 CF3 ほか）。組み合わせのラベル（NHFmoc・CH2OH・CO2tBu・BF3K・左向きの HOH2C）も規則で読む。「略号を展開」「略号に縮約」で行き来できる。「略号の辞書…」で確かめ・自分の略号を足せる。ChemDraw のファイルで構造の抜けたラベルは開くときに補う。設計は [docs/abbreviation-labels.md](docs/abbreviation-labels.md) |
| 環 | 3〜8員環・ベンゼン・椅子形シクロヘキサン。「芳香環・雛形」からナフタレン・ピリジン・インドールなどの芳香環 17 種とアミノ酸・糖・核酸塩基・骨格。何もない所に置く、結合をクリックして縮環、原子をクリックしてその原子を共有する環 |
| 選択・編集 | 矩形・投げ縄、Shift で追加、ダブルクリックで分子全体。ドラッグで移動（重なった原子はまとまる）、ハンドルで回転（Shift で 15° 刻み）、左右・上下の反転、削除、切り取り・コピー・貼り付け |
| 反応スキーム | 反応矢印（通常・平衡・逆合成）、＋記号、文字（矢印の上下の条件。数字ははじめから化学式の書き方で下付き、下付き・上付き・斜体のボタン）。矢印をクリックして種類を変える |
| 整形 | Clean Structure（RDKit の2D座標を元の位置と向きに重ねる）、横・縦にそろえる。塩としてまとめる（酸と塩基を 1 つの化合物に）、立体の表し方（abs・rac・rel。CXSMILES・MOL V3000・CDXML に入る）。設計は [docs/salt-design.md](docs/salt-design.md) |
| 反応スキーム（データ） | 分子を選んでスキームを始め、基質・生成物を足し、段ごとに試薬（当量）・溶媒・温度・時間・収率・ノート番号を入れると、書式どおりに自動で配置する。書式は ACS（条件を矢印の上下）・脚注（Reagents and conditions）・研究室のメモ（呼び名・ノート番号つき）から選び、画面で細かく直して自分のテンプレートとして保存できる。分子をドラッグしてスキームの矢印（基質）や右端（次の段の生成物）へ入れられる。化合物番号と呼び名、番号を一度に振る。段ごとの化学量論表（最初の基質の量から各試薬の mmol・mg・µL と理論収量、Excel に貼れる形でコピー）。描いた反応式をスキームのデータにする。スキームを複製して条件だけ変える（化合物は共有）。キャンバスで分子を直すと化合物のデータも直る |
| プロジェクト | キャンバスの左に開閉できるライブラリの列。プロジェクトごとに化合物を登録し（同じ構造は InChIKey で検出して知らせる）、番号・呼び名・メモを付け、文字や部分構造で探し、クリックかドラッグでキャンバスに置く。置いた分子を直すと知らせ、「ライブラリを更新」「別の化合物として登録」「つながりを外す」を選べる。図をプロジェクトに保存して開き直せる。部品のパレット（R のラベルをつなぐ点にした母核・保護基を、原子をクリックしてつなぐ）。一式（JSON・zip。zip には図の CDXML・SVG、化合物の SDF・CSV、表の CSV が入る）と化合物（SDF）の書き出し。保存先はブラウザの中（IndexedDB） |
| 検討表 | 条件検討型（試薬・溶媒・温度・時間・後処理・精製・収率）と SAR 型（母核の R1・R2 と置換基の列）のひな形。表の上に共通の反応式（スキーム）か母核を描き、論文の Table の体裁（罫線3本・題・注の記号）で並べる。列は種類つきで足し・消し・並べ替え、見出し・単位・注の記号を直せる。置換基の列は `*c1ccc(OC)cc1` のような * つきの SMILES なら構造で描く。Excel からの貼り付け（見出しで列を合わせる）、タブ区切りのコピー、CSV。行の条件で反応式を作る（化合物は共有） |
| 分析 | 選んだ分子（無ければ全部）の組成式・分子量・精密質量・m/z（[M+H]⁺ など）・元素分析値・logP・TPSA・HBD/HBA・Lipinski。値をクリックでコピー、キャンバスに文字として貼れる。R/S の表示、構造チェック（価数・立体の未指定・電荷） |
| 見本 | 上のバーの「見本…」で、アスピリン・タキソール・Boc カップリング・3段のスキーム・条件検討の表・SAR の表を開ける |
| 文書 | 新規・開く・保存（`.acedoc`、版 3。エディタの文書をそのまま JSON で保存）。ブラウザに自動保存し、開き直すと続きから |
| 入出力 | 読み込み: SMILES・反応 SMILES（A.B>C>D）・MOL・CDXML・CDX、PowerPoint（.pptx）に貼った Cocat の図とデータ入りの PNG（開き直し。設計は [docs/reopen-figure.md](docs/reopen-figure.md)）。書き出し: SMILES（反応があれば反応 SMILES）・MOL・CDXML・CDX・SVG・PNG（300 dpi。開き直すための図のデータ入り）。コピーで PowerPoint に貼った図も開き直せる。ファイル名を付けられる（開いたファイルの名前を引き継ぐ） |

## 完了条件の確かめ方と結果

### 1. アスピリン・タキソール骨格・Boc 保護アミノ酸の縮合スキームを5分以内に描ける

`e2e/scenarios.spec.ts` が、画面の操作（クリック・ドラッグ・キー）だけで3つを描き、SMILES が正しいことを確かめる。人の手数の目安として、操作の回数を出力する。

| 構造 | 操作の回数 | 人の目安（1操作 4 秒） |
| --- | --- | --- |
| アスピリン | 16 | 約 1 分 |
| タキサン骨格（6-8-6 の三環と C15 の橋、メチル5つ） | 15 | 約 1 分 |
| Boc-Ala-OH ＋ H-Gly-OMe → Boc-Ala-Gly-OMe（条件の文字と＋を含む） | 44 | 約 3 分 |

実際に人が5分以内に描けるかは、手で測って確かめる（操作の回数は、迷わずに描いたときの下限）。

### 2. 描いた構造の SMILES が RDKit で正しく解釈される

`tests/structures.test.ts` が、主要な構造22種（アスピリン、カフェイン、ペニシリン G、モルヒネ、コレステロール、ストリキニーネ、タキソールなど。立体・電荷・橋かけ環を含む）について、エディタのデータモデル → SMILES・MOL・CDXML → 読み直し、と Clean Structure の後で、立体を含めて同じ構造になることを確かめる。環ツールや結合ツールの操作で描いた構造は `tests/*.test.ts` と `e2e/*.spec.ts` で確かめている。

### 3. 書き出した CDXML が ChemDraw で崩れない

ChemDraw が手元に無くても確かめられるよう、2段階にしている。

**(a) ChemDraw 以外のソフトで読む（自動）**

```sh
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
npm run verify:cdxml
```

`out/` に見本の CDXML（22種の構造、略号、反応スキーム）を書き出し、次の2つで読んで、期待する SMILES と比べる。

- RDKit（Python 版）: Revvity（ChemDraw の開発元）の CDXML ライブラリを組み込んで読む（`Chem.HasChemDrawCDXSupport()` が True）。反応は `<scheme>` / `<step>` から `ReactionsFromCDXMLFile` で読む
- Indigo（EPAM）: 別の実装で読み、`out/*.indigo.png` に描く。矢印・＋・条件の文字の並びを目で確かめられる

2026-10-23 の時点で 27/27 が両方で OK（分子・立体・略号の Fragment ノード・反応の反応物・生成物、検討表つきの反応式）。

**(b) ChemDraw で開く（手で）**

ChemDraw を使える環境が手に入ったら、次を確かめる。

1. `npm run dev` で開き、上の3つを描いて「CDXML」で書き出す（または `out/*.cdxml` を使う）
2. ChemDraw で開き、次を見る
   - 結合長・線幅・フォントが ACS Document 1996 になっている（File → Document Settings）
   - 原子のラベル（OH, H2N, NH, Boc）の位置と、くさびの向き
   - 反応矢印・＋・矢印の上下の文字の位置
   - 略号（Boc）を右クリック → Expand Label で展開できる
   - Structure → Check Structure でエラーが出ない
   - 反応を選んで Edit → Copy As → SMILES（または Reaction SMILES）が、エディタの SMILES と同じ
3. ChemDraw で保存し直した CDXML を、このエディタで読み込めること

## 既知の課題

- Clean Structure は RDKit の2D座標をそのまま使うため、橋かけ環（タキサンの A 環など）が窮屈になる。椅子形は平らに戻る
- 描いた反応式（スキームのデータの無いもの）の解析は、矢印が左から右へ一列に並ぶものとして扱う（複数の行や縦の矢印は未対応）。スキームのデータがあれば、折り返した図でもデータから反応 SMILES と CDXML の段を作る
- 二重結合の線の位置の自動判定は、鎖の中で ChemDraw と違う側になることがある（二重結合ツールでクリックして変えられる）
- CDXML の矢印は、旧来の `<graphic>`（ArrowType）で書く。ChemDraw 12 以降が書く `<arrow>` 要素は読むだけ
- 2本以上の結合を持つ原子に略号は付けられない（価数エラーとして赤枠で示す）

## 構成

```
src/chem/    データモデル・幾何・元素と水素・編集の操作（結合・環・選択・略号・反応・Clean・整列）
src/render/  文書を描画の図形（線・多角形・文字）にする。画面と SVG/PNG の書き出しで共用
src/io/      SMILES・MOL・CDXML・SVG・PNG の入出力、CDXML 用の小さな XML パーサー
src/editor/  状態（undo/redo）・当たり判定・ツールごとのマウス操作・ショートカット
src/ui/      React の画面
tools/       CDXML を RDKit（ChemDraw のライブラリ）と Indigo で確かめるスクリプト
```
