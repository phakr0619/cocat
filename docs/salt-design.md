## 1. 塩（まとまり）

### 考え方

離れた複数の部分を、1 つの化合物（まとまり）として持つ。

- 原子に `unit`（まとまりの印。文書の中で一意な `u…`）を付ける
- 同じ印の連結成分を 1 つの分子にする `molecules()`（`src/chem/model.ts`）を使う
- 原子を動かしたり直したりしても、まとまりは崩れない
- 結合でつながった原子は、もともと同じ分子なので印が無くてよい

「1 つの化合物」を数える所は、連結成分（`fragments()`）ではなく `molecules()` を使う。

- 分析（`targetFragments`）
- スキーム（`freeFragments`・`reactionSteps`・`schemeObjects`・`syncSchemes`）
- 検討表の同期
- ライブラリ（`linkedFragments`）
- ダブルクリックの選択（`fragmentOf`）
- 整列

Clean Structure と SMILES の展開は、今までどおり連結成分ごとに扱う。

### 作り方

| 作り方 | 中身 |
| --- | --- |
| 選んでまとめる | 「整える」→「塩としてまとめる」（選んだ 2 つ以上の分子）、「まとまりを解く」（`src/chem/salt.ts`） |
| 読み込み | SMILES・MOL で、電荷を持つ部分があり全体の電荷が 0 なら、全体を 1 つの塩にする（`groupIonsOnImport`）。CDXML・CDX の `<group>` の中に分子が 2 つ以上あれば 1 つの塩にする |
| スキーム・ライブラリ | 離れた部分を持つ化合物の構造は、全体を 1 つのまとまり（`unit: 'u'`）として持つ（`structureFrom`） |
| 置く・貼り付ける | まとまりの印を、文書の中で新しい値へ振り直す（`remapUnits`）。元の塩と混ざらないようにするため |

### まとめたあとの動き

| 場所 | 動き |
| --- | --- |
| キャンバス | クリックは原子 1 つを選ぶ（今までどおり）。ダブルクリックで塩全体を選ぶ。選んだ原子がまとまりに入っていれば、まとまり全体を点線の枠で示す |
| 分析 | 1 枚のカードで出す。組成式・分子量・元素分析は塩全体。「成分」に `C9H13NO·HCl`・`C9H14NO⁺·Cl⁻`・`(C2H3O2⁻)2·Ca2+` の形で出す。m/z は炭素を含む成分ごと（イオンは M⁺・M⁻、中性は [M+H]⁺）。HCl・Na⁺ などの無機の成分の m/z は出さない |
| スキーム | 塩が 1 つの化合物。化学量論表は塩の分子量で計算する |
| ライブラリ | 1 つの化合物として登録する。InChIKey は成分ごとの立体を区別するので、ジアステレオマー塩（(R)-酸・(R)-アミンと (S)-酸・(R)-アミン）は別の化合物になる |
| SMILES・MOL・SDF | `A.B`（1 つの Molfile に 2 つの部分） |
| CDXML・CDX | 塩の部分を `<group>` で包む。反応の段（`ReactionStepReactants` など）は、塩なら group の id を指す |

CDXML の反応の段は、段の物（分子）の原子から fragment か group の id を引く。以前は fragment の番号で引いていたが、段の物をまとまりごとに数えるようにしたので、塩の所で番号がずれるため。

## 2. ラベルで書く塩（NH2Cl・NH·HCl）

窒素・リンの原子のラベルに、塩の書き方をそのまま入れられる（`src/chem/label.ts` の `parseSaltLabel`）。

| 入れる文字 | 中身 | 図 |
| --- | --- | --- |
| `NH2Cl`・`NH2+Cl-`・`ClH2N`（左向き） | 陽イオン（水素が 1 つ増える）と X⁻ | 入れた書き方のまま |
| `NH·HCl`・`NH.HCl`・`HCl·HN` | 中性のアミンと HX | 同じ |
| Br・I も同じ形 | | |

- 原子には塩の印（`salt: { x, style }`）だけを持つ。対イオンは図に原子として持たず、書き出しと計算のときに原子として足す（`expandSalts`、`src/chem/saltLabel.ts`）。略号の展開と同じ考え方
- 水素の数を書いたときは、その原子の陽イオン（·H の形なら中性）の水素の数と合うときだけ塩として読む
  - 1 級アミンに `NHCl` と書くのは、N−Cl の結合を持つクロロアミンの書き方なので、塩としては読まない。正しい書き方（`NH3Cl`）を知らせる
- 元素を変えたり略号にしたりすると、塩の印は外れる
- CDXML・CDX では、ChemDraw に同じ書き方が無いので、陽イオンと対イオンの原子にして `<group>` で包んで書く。読み直すと、ラベルではなく 2 つの原子の塩になる（化学としては同じ）

## 3. rac・rel（拡張立体表記）

不斉中心を 3 つの組に分ける（`src/chem/stereoGroups.ts`）。

| 組 | 意味 | 図 | CXSMILES | Molfile V3000 | CDXML |
| --- | --- | --- | --- | --- | --- |
| 絶対配置（abs） | 描いたくさびのとおり | 何も出さない（組が混ざるときは中心に `abs`） | `a:` | `MDLV30/STEABS` | （書かない） |
| ラセミ（and） | 描いた立体と鏡像の 1:1 | 分子の下に `rac`（一部の中心なら `&1`） | `&1:` | `MDLV30/STERAC1` | `EnhancedStereoType="And"` |
| 相対配置（or） | 描いた立体か鏡像のどちらか一方 | 分子の下に `rel`（一部の中心なら `or1`） | `o1:` | `MDLV30/STEREL1` | `EnhancedStereoType="Or"` |

### 操作

「整える」→「立体の表し方」で、選んだ不斉中心に組を付ける。選んだ原子に不斉中心が無ければ、選んだ分子の不斉中心すべてに付ける。

- 不斉中心は、くさび・破線のくさびの細い側の原子
- and・or は、同じ分子のほかの組と重ならない番号にする

### 書き出しと読み込み

| 形式 | 書き方 |
| --- | --- |
| SMILES | 組があれば CXSMILES（`C[C@H](N)[C@H](C)O \|&1:1,3\|`） |
| MOL | 組があれば V3000（RDKit で V3000 にしてから COLLECTION を足す） |
| CDXML・CDX | `EnhancedStereoType`・`EnhancedStereoGroupNum`（CDX は 0x0446・0x0447。RDKit が書いた CDX で番号を確かめた） |

- どの形式も、読み込みで組を戻す
- RDKit の `get_molblock` は組があると V3000 を返すので、読み直す所は `get_v2Kmolblock` を使う
- 反応 SMILES の中では組を書けないので、外す（反応 SMILES は今までどおり）
- ライブラリ: InChI は rac と光学活性体を区別しないので、組があれば InChIKey に組の書き方を足して、別の化合物として登録できるようにした

## 光学分割のスキームの描き方（例）

1. rac-酸を描き、選んで「整える」→「ラセミ（rac・&）」
2. (R)-アミンを描く（くさびのまま。絶対配置）
3. 塩を描く（酸とアミンを描いて選び「塩としてまとめる」、または `[O-]…[NH3+]…` の SMILES を読み込む）
4. スキームにする。塩は 1 つの化合物なので、番号は 1 つ。結晶と母液の 2 つの塩を、1 段目の生成物として並べられる
