# ロードマップ

2026-11-12 作成。Cocat で作ったものと、これから考えるもの。段の名前（M0〜M6）は、コードのコメントやコミットメッセージにも出てくる。

## 目指す姿

**確かめ付きの、AI と一緒に使える化学構造式・反応スキームのエディタ。**

- 主役は描く道具で、AI は手伝い役。AI なしでも使える構造式とスキームのエディタ（M0〜M2）が土台で、その上に「言葉から作る」「言葉で直す」（M3）を乗せる
- 化学は「それらしい」では困るので、AI の答えは下書きにし、形・構造（RDKit）・元素のつじつま・分子式の差・立体を確かめてから人が確定する。確定するまで文書は変わらず、元に戻すで戻せる
- 描いた構造はブラウザの中だけに置く。AI の機能は、利用者が自分の API キーで、ブラウザから AI の会社へ直接呼ぶ（BYOK）
- 選べるモデルを足すときは、決まった評価（`npm run eval:llm` など）を流し、8 割以上が正しく、黙って間違えたものが無いものだけを選べるようにする

## 作ったもの

| 段 | 内容 |
| --- | --- |
| M0 | 下地: CI、文書の保存形式（`.acedoc`）、表示の移動など |
| M1 | 分析パネル: 組成式・分子量・精密質量・元素分析値・m/z、logP・TPSA など、R/S、構造チェック |
| M2 | 反応スキームのデータ、書式テンプレート（ACS 風など）、自動レイアウト、化学量論表、ブラウザの中のプロジェクト（化合物のライブラリ・反応の使い回し・部品）、検討表 |
| M3 | AI の層（Gemini、BYOK）、言葉からスキーム、言葉で直す、仕上げの一括の指示、画像からスキーム、実験項の文章 |
| M5 | 名前から構造を置く（辞書・ライブラリ・SMILES・OPSIN・Gemini の順）、NMR の目安（教科書の加成則）、CAS 番号の形と検査数字の確認 |
| M6 | 論文の PDF からスキーム（図の範囲を選ぶ・AI で探す、本文と SI の化合物番号で突き合わせる） |

形式と決まりの説明: 塩と立体のまとまり（`docs/salt-design.md`）、略号のラベル（`docs/abbreviation-labels.md`）、図を開き直す（`docs/reopen-figure.md`）、OPSIN のサーバー（`docs/opsin-server.md`）。公開の手順は `docs/hosting.md`。

## これから考えるもの（順番は決めていない）

- NMR の予測を、実測のデータベース（NMRShiftDB2）で強くする。データのライセンスは「データを使って作ったソフトウェアはオープンソースであること」を求めるので、OSS になった今は条件を満たせるかを確かめてから
- CAS 番号から構造を引く。どのデータベースから引くかと、その利用条件を確かめてから
- スキームから文章や表を作る機能を広げる
- ほかの AI の会社（Claude・OpenAI など）を BYOK で選べるようにする。足すたびに評価を流す
