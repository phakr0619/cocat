ai-chem-editor · Phase 1 ＋ M0〜M2 · 2026-10-23

Cocat ガイド

ChemDraw に近い操作で構造式と反応スキームを描き、SMILES・MOL・CDXML でやり取りできる Web のエディタです。反応スキームと検討表はデータとして持つので、書式を切り替えて描き直せます。描いたものはプロジェクトに書き溜められます。このガイドでは、できることを画面の写真つきでひと通り説明します。

  • 描画 SVG を自前で組み立て
  • 化学の計算 RDKit.js
  • PDF を開く pdf.js（Apache-2.0。端末の中で開く）
  • 表示 ACS Document 1996
  • テスト 単体 141・E2E 51・CDXML 検証 27

00はじめに

手元のパソコンで動かします。Node.js を入れたうえで、リポジトリのフォルダで次を実行し、表示された http://localhost:5173 をブラウザで開きます。

npm install npm run dev

開くと RDKit（化学の計算部分、約 7MB）を読み込み、白いキャンバスが出ます。左のツールを選んでキャンバスをクリックすれば、すぐ描けます。何ができるかを先に見たいときは、上のバーの「ファイル」→「見本を開く」から、アスピリン・タキソール・Boc カップリング・3段のスキーム・条件検討の表・SAR の表を開けます（元に戻すで前の図に戻ります）。

描いた内容はブラウザに自動で保存され、ページを開き直すと続きから描けます。ファイルとして残すときは、上のバーの「ファイル」→「保存」（Ctrl+S）で .acedoc の文書として保存し、「開く…」（Ctrl+O）で開き直します。「新規」は元に戻すで取り消せます。

表示はホイールか右ボタンのドラッグ（スペース＋ドラッグ・中ボタンのドラッグでも）で動かし、Ctrl＋ホイールでカーソルの位置を中心に拡大・縮小します。

02結合と鎖

結合ツールは6種類。どれも同じ操作で描けます。

操作結果
何もない所をクリック右上 30° に結合が1本できます
原子をクリック空いている向きに1本伸びます。鎖の末端なら 120° のジグザグに続きます。既存の原子とぶつかる向きは避けます
ドラッグ30° 刻みの向きに描けます。離した位置が原子の近くなら、その原子につながります（環を閉じるときなど）
既存の結合をクリック単結合ツールでは 単→二→三→単。二重結合ツールでは線の位置を 自動→中央→右→左。同じくさびでクリックすると向きが反転します

二重結合の2本目の線は、環の中では環の内側に、鎖では置換基の多い側に自動で置きます。C=O のように片方が末端のときは中央に置きます。

結合の道具には、ほかに太い結合・点線の結合・配位結合（矢印の形。M→L）もあります。配位結合は構造（SMILES・Molfile）には入れず、図にだけ描きます。

鎖ツール

ドラッグした長さぶんのジグザグ鎖を一度に描きます。ドラッグ中は、何本の結合になるかを数字で示します。

結合その結合を共有して縮環します。原子の少ない側（環の外側）に置きます。ベンゼンは二重結合が隣り合わないように置きます

雛形

環の道具の下の「芳香環・雛形」から、芳香環（ベンゼン・ナフタレン・ピリジン・ピロール・フラン・チオフェン・インドール・キノリンなど 17 種。はじめに開くタブ）・アミノ酸（L 体の20種）・糖（D 体）・核酸塩基・よく使う骨格（ステロイド・ピペリジン・モルホリンなど）を選び、クリックした所に置けます。

略号のラベルと略号の辞書

  • 組み合わせのラベル: 原子のラベルに、標準の略号のほか、NHFmoc・OPMB・N(Boc)2 のような「原子＋略号」、CH2OH・CO2tBu・SO2Ph のような縮約式、BF3K・CO2Na のような塩を書けます。左向きの書き方（HOH2C・FmocHN）も読みます。読み方は決まった規則だけで、AI は使いません
  • 書き出し: CDX・CDXML には、どの略号も中身の構造を入れます（ChemDraw が辞書で読めない略号でも、構造が入ります）
  • ChemDraw のファイルの抜け: ChemDraw で構造が埋め込まれなかったラベル（文字だけのもの）は、開くときにラベルから構造を補い、「構造の抜けていたラベル n 個を補いました」と知らせます。読めないラベルは赤い枠で示します。補ったファイルを書き出し直すと、構造の入った CDX になります
  • 略号の辞書: 「整える」→「略号の辞書…」で、標準の略号を構造の絵つきで見られ、「ラベルを試す」で書き方がどう読まれるかを確かめられます。自分の略号は、名前と SMILES（結合する所を *）で足すか、結合する所を R にした置換基を描いて選び「選んだ構造から」で足します。自分の略号はブラウザが覚え、使った文書にも入ります

塩と rac・rel

  • 塩をラベルで書く: アミンの N のラベルに NH2Cl・NH3Br・NH·HCl のように入れると、塩酸塩・臭化水素酸塩として扱います（図は書いたとおり）。NH2Cl の形は陽イオンと Cl⁻、NH·HCl の形は中性のアミンと HCl として SMILES・分子量に入ります。水素の数がその N に合わない書き方は知らせます（1 級アミンの塩は NH3Cl）
  • 塩としてまとめる: 酸と塩基（光学分割のキラルアミンの塩など）を選んで「整える」→「塩としてまとめる」で、1 つの化合物になります。分析・スキーム・ライブラリで 1 つに扱い、ダブルクリックで塩全体を選びます。「まとまりを解く」で戻ります。C[NH3+].[Cl-] のように電荷が打ち消し合う SMILES は、読み込むと 1 つの塩になります
  • rac・rel: 不斉中心（くさびの細い側）か分子を選んで「整える」→「立体の表し方」で、絶対配置（abs）・ラセミ（rac）・相対配置（rel）を選びます。分子の中心がすべて同じ組なら分子の下に rac・rel、一部だけなら中心ごとに &1・or1 を出します。SMILES（CXSMILES の |&1:…|）・MOL（V3000）・CDXML・CDX に入ります

05選択と編集

  • 矩形選択・投げ縄選択でドラッグして範囲を選びます。Shift で追加
  • 原子・結合のクリックで1つ選択、ダブルクリックで分子全体
  • 選んだ物のドラッグで移動。原子を別の原子に重ねると1つにまとまります
  • 枠の上の丸いハンドルをドラッグして回転（Shift で 15° 刻み）
  • 左右・上下の反転、削除、切り取り・コピー・貼り付け
  • 消しゴムツールで、クリックした物を消す

道具・メニューできること

06反応スキーム

反応物と生成物は、矢印の左右の位置で自動で判断します。矢印の上下に置いた文字や分子は、反応条件として扱います。＋記号は「＋」ツールで置きます。

07スキームのデータと書式

反応スキームを「絵」ではなく、化合物と段（反応）のデータとして持ちます。書式を選ぶと、同じ中身から描き直します。

作り方

  • 右の欄の「＋ 反応スキーム」の「名前や SMILES から作る」で、段ごとに基質・試薬・条件・生成物を入れて「スキームにする」。名前は手元の辞書と OPSIN で構造にします（AI は使いません）。空の欄と読めない名前は枠になり、キャンバスに分子を描いて選び、化合物の「選んだ分子にする」で埋められます
  • 分子を選んで、右の欄の「＋ 反応スキーム」の「選んだ分子からスキームを始める」。続けて「＋基質」（カップリングの相手）、「選んだ分子を生成物にして段を足す」で段を重ねます
  • 描いてある反応式（分子・矢印・条件の文字）は「描いた反応式をスキームにする」でデータにできます。条件の文字は試薬・溶媒・温度・時間・収率に振り分けます
  • 分子をドラッグして、スキームの矢印（その段の基質）や右端（次の段の生成物）へ入れることもできます
  • 段ごとに 試薬（当量は括弧で）・溶媒・温度・時間・収率・ノート番号 を入れます。化合物には番号（「12」「3a」「ABC-123-01」など自由。無くてもよい）と呼び名を付けられ、「番号を振る」で出てくる順に 1, 2, 3… を振ります
  • キャンバスで分子を直すと、化合物のデータも直り、描き直されます。スキームを丸ごと動かすと置き場所が変わります
  • 「スキームを複製」で、化合物を共有したまま条件だけ変えた反応を作れます（番号や構造を直すと両方に反映）
  • 「固定する」で、そのスキームを今の形で固定します。ほかのスキームと共有する化合物の番号・構造や書式を後で直しても、固定した図は変わりません（発表やノートに使った図を守るとき）。固定中は欄の入力を触れなくなり、「固定を外す」で今の中身で描き直します。固定した図は、言葉での「直す」と「仕上げ」の対象に入りません
  • 欄の「化合物」には、構造の小さな絵が付きます。どの化合物の番号・呼び名かが分かります

書式

プリセットは ACS（条件を矢印の上下）・脚注（Reagents and conditions）・研究室のメモ（呼び名・ノート番号つき）の3つです。「書式を編集」で、条件の置き場所・当量と収率の書き方・収率の位置・段の記号（a, b / i, ii）・区切り・幅・番号の太字・呼び名・ノート番号を変えられ、「自分のテンプレート」としてブラウザに保存できます。

行の幅に入らないスキームは折り返します。「行の折り返し位置」で、矢印の後と化合物の後のどちらで折り返すかを選びます。両方を選ぶと、入る所まで詰めて並べます。「A + B」のように＋でつないだ化合物の途中では折り返しません。ページの設定があるときは、行の幅をページに合わせ、ページの右端の少し内側で折り返します。

化学量論表

最初の基質の量（mg か mmol）を入れると、当量から各試薬の mmol・mg・µL（密度があれば）と生成物の理論収量を出します。よく使う試薬約 50 種の分子量と密度を持っていて、表の上で直すこともできます。「表をコピー」で Excel に貼れる形（タブ区切り）になります。g・kg での仕込みや、溶媒の量・含量・ロットまで残すときは、段の「＋ 実験の記録を作る」を使います（実験の記録）。

スキームのデータがあれば、折り返した図でも、反応 SMILES と CDXML の段（<step>）はデータの順と中身で書き出します。

08検討表

条件検討や SAR の表を、論文の Table の体裁（題・罫線3本・注）で描きます。表の上には共通の反応式か母核を置きます。

  • 条件検討の表: スキームがあれば、その反応式を表の上に描きます。列は 試薬（当量）・溶媒・温度・時間・後処理・精製・収率
  • SAR の表: 原子のラベルに R1・R2 を付けた分子を選んで作ると、それを母核として表の上に描きます。置換基の列に *c1ccc(OC)cc1 のように * でつなぐ点を示した SMILES を入れると構造で描き、Ph・4-ClC6H4 のような文字はそのまま化学式の書き方で描きます
  • 列は種類つきで足し・消し・並べ替えでき、見出し・単位・注の記号（a, b…）を直せます。表の下の注は1行に1つ書きます
  • セルの終わりに ^b と書くと、表の下の注 b を指す記号（ᵇ）を付けます（85^b、いくつかなら rt^a,c）。行から反応式を作るときは、記号を外して写します
  • 行は左端のつまみ（⠿）のドラッグか、右端の ↑↓ で並べ替えます
  • 「Excel から貼り付け」で、Excel の範囲をそのまま行として入れられます。1行目が見出しなら見出しで列を合わせます。「コピー」でタブ区切り、「CSV」で Excel で開けるファイル、「Excel」で .xlsx（題と見出しは太字、数は数として入ります）になります
  • 行の「→式」で、その行の条件を入れた反応式を表の下に作ります（「最良の条件でスキームへ」）
  • 表を丸ごとドラッグすると、反応式ごと動きます。SAR の母核をキャンバスで直すと、表の母核のデータも直ります

09実験の記録

スキームの 1 段を行った 1 回ぶんの、仕込み・操作の流れ・重さ・操作ごとの記録を入れます。入れたデータから、フロー図と物質収支を自動で描きます。

作り方

  • スキームの欄の段を開き、「＋ 実験の記録を作る」を押します。その段の基質・試薬・溶媒が仕込みに入り、化学量論表に基準の量があれば量も入ります
  • 右の欄の「この文書」の「＋ 実験の記録」からも作れます。スキームが無くても作れます
  • 同じ段に、何回ぶんでも作れます。作った後は、記録の値がその回の値になり、スキームの当量を直しても変わりません

仕込み

mmol と、基質 1 g あたりの溶媒量（mL/g）は自動で出ます。含量（wt%）を入れると、mmol と収率を含量で補正します。「入れる操作」で、後処理で入れる水や洗浄液を、その操作に入れた物にします。

操作と記録

  • 操作は「＋ 操作を足す…」で足し、↑↓ で並べ替えます。種類は、仕込み・反応・滴下・加熱と冷却・クエンチ・分液・洗浄・抽出・濃縮・溶媒置換・晶析・ろ過・乾燥・カラム・その他から選び、名前は自由に直せます
  • 操作ごとに、外へ出る物（水層・母液・留出など）と、次へ進む物の重さを入れます。最後の操作の「得た重さ」が収量です
  • 重さの入っていない物が 1 つだけなら、差から出します。そのことは図と「確かめてほしい所」に出ます
  • 外へ出る物に生成物の含量（wt%）を入れると、右の欄に「生成物の行方」が出ます
  • 記録は、下の欄に入れて Enter で足します。「10:32 TFA を入れる」のように時刻から打つと、その時刻の記録になります。時刻を打たなければ、今の時刻が入ります

フロー図と収支

値出し方
操作ごとの収支出た重さ（外へ出た物 ＋ 次へ進む物）÷ 入った重さ（前の操作から来た物 ＋ 入れた物）
収率得た重さ ÷ 理論収量（最初の基質の物質量 × 生成物の分子量）
含量で補正した収率基質と生成物の含量を掛けて出した収率
PMI仕込みの重さの合計（水と溶媒を含む）÷ 得た重さ。役割を「溶媒」「水・水溶液」にした物の分を、内訳として出します

「フロー図」で、横に並べる書式と縦に並べる書式を切り替えます。「重さを出す」を外すと、重さと収支を書かない図になります。収支が 100% から 5% より離れたとき、出た重さが入った重さより多いとき、記録の時刻が前の行より早いときなどは、右の欄の「確かめてほしい所」に出ます。

出すもの

右の欄の「この記録から」にあります。

  • 「PDF・印刷」: 反応式・仕込み・フロー図・結果・収支・操作と記録を、A4 の 1 枚にまとめます
  • 「表をコピー」: 仕込み・操作と記録・収支・結果を、Excel に貼れる形でコピーします
  • 「検討表の行にする」: 回ごとのノート番号・仕込みの量・収量・収率・含量・PMI を並べる表に、この記録の行を入れます

実験の記録は、このブラウザの中と文書のファイルだけに保存します。署名や変更の履歴は残らないので、正式な記録は実験ノートに残してください。決まりの詳しい説明は docs/process-record.md にあります。

10プロジェクト（ライブラリ・部品・図・表）

キャンバスの左の列に、プロジェクトごとの化合物・図・検討表・部品を書き溜めます。保存先はこのブラウザの中（IndexedDB）で、PC の外には出ません。

  • 化合物: キャンバスの分子を選んで「選んだ分子を登録」。描き方が違っても同じ構造（InChIKey が同じ）なら知らせて、「登録済みのものにつなぐ」か「別の化合物として登録」かを選べます。番号（無くてよい）・呼び名・メモを付け、番号・呼び名・組成式や部分構造（「選んだ分子を含むものだけ」）で探せます
  • 置く: 一覧の絵をクリックすると表示の中央に、ドラッグすると好きな場所に置きます。置いた分子をキャンバスで直すと「ライブラリの◯◯と違います」と知らせ、「ライブラリを更新」「別の化合物として登録」「つながりを外す」から選びます。黙って更新したり、描いている途中の分子を勝手に結び付けたりはしません
  • 部品: 原子のラベルに R を付けた分子を選んで「選んだ分子を部品にする」。部品を選んでキャンバスの原子をクリックすると、そこに結合1本でつなぎます。何もない所をクリックすると置きます
  • 図: 今の図に名前を付けて保存し、あとで開いたり上書きしたりできます
  • 表: 今の図の検討表を、表の上の反応式ごと「入れる」。入れた表は「置く」で、ほかの図の下に置き直せます（置いた図の中では新しい化合物になり、元の図とは共有しません）
  • 書き出し: 「一式（JSON）」は別の PC で読み込めます。「一式（zip）」には、図ごとの CDXML・SVG・文書、図の中の検討表の CSV、入れた検討表の .xlsx・CSV、化合物の SDF・CSV が入り、ChemDraw や Excel で開けます。「化合物（SDF）」は番号・呼び名・メモつきです

11Clean Structure・整列

Ctrl+Shift+K（または上のバーの「整える」→「Clean Structure」）で、選んだ分子（選んでいなければ全部）の形を整えます。RDKit の2D座標を使い、元の位置と向きにできるだけ重ねるので、分子が大きく動いたり裏返ったりしません。

「整える」→「横にそろえる」「縦にそろえる」で、分子・矢印・＋記号の中心の高さ（または左右の位置）をそろえます。矢印を動かすときは、上下の条件の文字も一緒に動きます。

NMR の予測（目安）

カードの「NMR の予測の目安（加成則）」を開くと、¹H と ¹³C の化学シフトの目安が出ます。教科書に載っている加成則（基本の値に、置換基ごとの寄与を足す表）で計算したもので、実測のデータベースは使っていません。

対象使う表
¹³C 脂肪族（sp3）Grant–Paul 型（α・β・γ・δ の炭素と立体の補正）に、OH・OR・C=O・ハロゲンなどの置換基の寄与を足す
¹³C ベンゼン環128.5 に、置換基の ipso・ortho・meta・para の寄与を足す
¹³C アルケン・アルキン123.3（アルキンは 71.9）に、同じ側・反対側の置換基の寄与を足す
¹³C カルボニル・ニトリルケトン・アルデヒド・酸・エステル・アミドなど種類ごとの基本の値に、共役と隣の枝分かれの補正
¹H 脂肪族Shoolery 型（CH₃ 0.90・CH₂ 1.20・CH 1.55 に、隣と 2 つ先の置換基の寄与）
¹H ベンゼン環・アルケン7.27 に置換基の ortho・meta・para の寄与。アルケンは Pascual–Meier–Simon の式（5.25 に gem・cis・trans の寄与。cis・trans は図の向きで読む）
  • 等価な原子（対称で同じ位置）は 1 行にまとめ、数（2H・2C など）を出します。
  • 行にマウスを載せると、その原子をキャンバスで緑に示します。クリックで固定、もう一度クリックで外します。
  • 「値をコピー」で 1H NMR (predicted, additivity rules): δ 7.89 (2H), … の形の文字をコピーします。予測値であることが分かる書き方にしています。
  • 表で読めない原子は「—」と「予測できない」の理由を出し、値は出しません。ピリジン・フランなどベンゼン以外の芳香環、ナフタレンなどの縮環、イミン・C=S、ホウ素・ケイ素などの置換基、芳香環の N に付いたメチル、CF₃ の炭素のように同じ炭素にヘテロ原子が 3 つ重なる形が対象外です。OH・NH の H は溶媒や濃度で大きく動くので出しません。
  • △ は、置換基が込み合う・小さな環の中など、加成則が当てになりにくい形の印です。

精度の目安: よく知られた化合物の教科書の実測値（CDCl₃）と比べたところ、表を書くときに見た 19 件では ¹³C の 100%（77 点）が ±5 ppm、¹H の 97%（61 点）が ±0.3 ppm に、表を書いた後に足した 12 件では ¹³C の 85%（48 点）、¹H の 92%（39 点）が収まりました。初めて見る分子では後の数字の方が実際に近いと考えてください。外れやすいのは、シクロヘキセン・シクロヘキサノンの環の CH₂、tert-ブチル基の付いたエーテル、DMF の N–CH₃、CH₂Cl₂ のように同じ炭素に置換基が重なる形です。帰属の確認や論文の値には、必ず実測を使ってください。

スライドに貼った図を開き直す

Cocat の「コピー」で PowerPoint に貼った図と、書き出した PNG を挿入した図は、あとで Cocat で開き直して直せます。ファイルのメニューの「SMILES・MOL・CDXML の読み込みと書き出し…」の「ファイルを開く」で、その PowerPoint のファイル（.pptx）を選びます。Cocat の図が 1 つならすぐ開き、2 つ以上ならスライドの番号と小さな絵の一覧から選びます。今の図と置き換わり、元に戻すと前の図に戻ります。直したら、もう一度コピーしてスライドの図と差し替えてください。

図の画像には、開き直すためのデータ（構造・条件・番号・呼び名など、その図に描いてあるもの）が目に見えない形で入っています。スライドを人に渡すと、受け取った人も Cocat で開けます。化合物のメモ、プロジェクトのほかの化合物、化学量論表の量、AI に送った文章は入れません。PowerPoint の「図として保存」で取り出した画像からは開けません（PowerPoint が描き直すため）。PowerPoint の SVG の図にも入りません。

読み込みは、右の欄に貼り付けて「読み込む」を押すか、「ファイルを開く」で選びます。形式は中身から自動で判定します。ほかのアプリでコピーした SMILES・Molfile・CDXML は、キャンバスに Ctrl+V で貼れます。

ChemDraw の代わりに、次の2つで書き出した CDXML を読み、期待どおりの構造になるかを確かめています。検討表つきの反応式を含む27ファイルすべて OK でした（表の罫線は矢頭の無い線、R1 は GenericNickname として書きます）。

  • RDKit（Python 版）: ChemDraw の開発元 Revvity の CDXML ライブラリを組み込んで読みます
  • Indigo: 別の実装で読み、画像に描きます（下の図）

ChemDraw 本体で開いての確認はまだです。確認の手順は README にまとめています。

17既知の課題と対象外

既知の課題

  • Clean Structure は RDKit の2D座標を使うため、橋かけ環（タキサンの A 環など）が窮屈になります。椅子形は平らに戻ります
  • 描いた反応式（スキームのデータにしていないもの）の解析は、矢印が左から右へ一列に並ぶ形にだけ対応しています。スキームのデータにすれば、折り返した図でも正しく書き出せます
  • プロジェクトは今のブラウザの中だけにあります。別の PC や人と共有するときは、一式の JSON か zip を渡します
  • 二重結合の線の位置の自動判定が、鎖の中で ChemDraw と違う側になることがあります（二重結合ツールでクリックすると変えられます）
  • 2本以上の結合を持つ原子には略号を付けられません（赤い枠で示します）

今回の対象外（将来の候補）

NMR の実測データベースによる予測（今は加成則の目安だけ）、3D、CAS 番号・PubChem での照合、複数ページ、質量分析のフラグメント・pKa。
