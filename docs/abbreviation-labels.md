# 略号のラベル: ラベルの書き方を読む・ChemDraw のファイルの抜けを補う・略号の辞書

2026-11-07 作成。ユーザーの声:
- 「ChemDraw で構造式の原子に置換基の略称を描くと、一部の置換基が正しく CDX に埋め込まれない（BF3K など）」
- 「略号の辞書は、必要に応じて確認したり追加できたりするといい」

## 調べたこと

- **このエディタの書き出し**
  - 略号は、ChemDraw と同じく中身の構造を埋め込んだ Fragment ノードで書く
  - 標準の略号 49 種をベンゼンに付けて CDXML と CDX に書き出し、RDKit（ChemDraw の部品入り）と Indigo で読んだ。98/98 が正しい構造だった
- **構造の抜けたラベル**（文字だけがあり、中身の構造が無いノード）
  - 保存の形を 6 通り作って、RDKit に読ませた
  - 多くの形で、**黙ってメチル基として読んだ**。BF3K を付けたベンゼンがトルエンになる
  - RDKit はラベルの文字を見ないので、抜けに気づけない
  - このエディタも、表に無いラベルは R、保存の形によっては炭素として読んでいた
- **判定の方法**
  - ラベルの文字と、そのノードの中身（元素）が合っているかを見比べれば、抜けを見つけられる

## 1. ラベルの読み方（`src/chem/condensed.ts`）

| 書き方 | 例 |
| --- | --- |
| 原子＋略号 | NHFmoc・OPMB・NHAc・N(Boc)2・NMe2・OTIPS・SiMe3・CH2OTBS・PPh2 |
| 縮約式 | CH2OH・CH2CH2OH・CHO・CO2tBu・COOH・CONH2・COMe・COCl・SO2Ph・SO2NH2・SO3H・CCl3・OCF3・CH(OMe)2・(CH2)3OH・CH=CH2・CCH・C2H5・N3・B(OH)2・PO(OEt)2 |
| 塩 | BF3K・CO2Na・SO3Na・ONa |
| 左向き | HOH2C・FmocHN・MeO2C・KF3B・Me2N・H2NOC |

### 読み方の手順

1. ラベルを部品に分ける
   - 部品は、元素と数・置換基の名前・括弧と数
   - 置換基の名前は、標準の略号と自分の辞書から長いものを先に取る
2. 原子価で、つなぐ所を決める
   - 新しい原子は、直前の開いている原子につなぐ
   - 同じ元素の数（F3・(OMe)2）は、同じ原子に付ける
3. 余った原子価を、二重・三重結合で埋める（CN → C≡N、CH=CH2）
4. 決まった読み方

| 場面 | 読み方 |
| --- | --- |
| C・P のあとの O | カルボニル（CO・PO）。CH2O… のように開きが 1 つなら単結合 |
| C のあとの O2 | エステル・カルボン酸（CO2R） |
| S のあとの O・O2・O3 | スルホキシド・スルホニル・スルホン酸 |
| N のあとの O2 | ニトロ |
| ホウ素に 4 本 | ボラート（B⁻） |
| アルカリ金属 | 対イオン。陰イオンが足りなければ、開いている原子を陰イオンにする（CO2Na の O⁻） |
| CnH2n+1 | 直鎖のアルキル |
| N3・NCO・C6H5・C6F5・C6H11 | 決まった部品 |

### 読めないときの扱い

- 略号を長く取る読み方で読めなければ、元素に分けて読み直す（COMe は OMe ではなく C(=O)Me）
- 右向きで読めなければ、部品の順を逆にして左向きとして読む
- 読めないもの（PG・CH5・NH4 など）は null を返す

### 使う所

| 場所 | 使い方 |
| --- | --- |
| 原子のラベルの入力（`parseLabel`） | 元素の書き方（OH・NH2・Cl）を先に読む。自分の辞書の名前は元素より先、ラベルの読み方は最後 |
| 図のラベル | 書いたとおり。左向きでは並べ直す（FmocHN） |
| 書き出し（CDXML・CDX） | 中身の構造を埋め込む |
| SMILES・MOL・分析 | 展開して数える。対イオン（BF3K の K⁺）は、前に作った塩（まとまり）の仕組みで、分子と同じ化合物にする |

略号の引き方は、`getAbbr`・`resolveAbbr`（`src/chem/abbreviations.ts`）にまとめた。順は **標準の表 → 利用者の辞書 → ラベルの読み方**。

## 2. ChemDraw のファイルの抜けを補う（`src/io/cdxml.ts` の `checkLabel`）

文字だけのラベルのノード（中に fragment の無いもの）は、ラベルの文字と中身（元素）が合っているかを確かめる。

| 場合 | 扱い |
| --- | --- |
| 合っている（O の OH、C の CH3・Me） | そのまま。知らせない |
| 合わない・中身が無い | ラベルの読み方で補う（BF3K・NHFmoc・OTBS・HOH2C） |
| 読めない | 炭素にせず、ラベルの文字のまま「構造の分からない置換基」にする（`valenceErrors` で赤い枠） |
| 置換基の記号（R・R1・Ar・X） | 構造が無いのが正しいので、枠を出さない |
| ChemDraw が中身を埋め込んだ略号（Fragment ノード） | 今までどおり中身を使う |

読み込んだあとに、ステータスバーに知らせる。

> 構造の抜けていたラベル n 個を、ラベルから補いました（…）。n 個のラベルは構造が分かりません（…）

## 3. 略号の辞書（`src/ui/AbbrDictionary.tsx`・`src/ui/abbrStore.ts`）

- 標準の略号（49 種）と、自分で足した略号を、構造の絵・SMILES つきで見る
- 「ラベルを試す」で、書いたラベルがどこから（標準・自分の辞書・ラベルの読み方）どの構造になるかを見る
- 自分の略号の足し方
  - 名前と SMILES（結合する所を `*`）を入れる
  - キャンバスで結合する所を R にした置換基を選んで「選んだ構造から」でも入れられる
  - `*` がちょうど 1 つか確かめ、`*` から始まる形にする（RDKit の rootedAtAtom）
  - 元素記号・標準の略号と同じ名前は断る
- 保存
  - 自分の辞書はブラウザに覚える（localStorage の `ai-chem-editor:abbr-user`）
  - 文書で使った自分の略号は、文書にも写す（`Doc.abbrDefs`）。自分の略号を部品にしたラベル（ONap）も含む
  - 別の PC で開いても読める
